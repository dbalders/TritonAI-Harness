# Getting started with TritonAI Harness

TritonAI Harness opens the workspace directly and skips the Connect, Agents, and Projects setup wizard. New desktop installations use the TritonAI workspace and starter conversation.

Use TritonAI Installer to install or repair the managed runtime. Update access in **Settings → Runtime** when credentials need attention.

To connect another computer, use **Settings → Connections**. Browser and mobile clients still need to authenticate or pair with a running Harness environment.

Add projects when you need them using **Add Project** in the command palette. Existing links to `/welcome` return to the workspace.

## Guided tour (experimental)

The guided tour is available in Nightly and development builds, and is off by default. Stable releases do not offer it. To try it in Nightly, turn on **Settings → General → Experimental → Guided tour**, then choose **Start tour**. It works in the desktop app and in a browser connected to a TritonAI server. With the experiment enabled, **Getting started** in the sidebar and **Open getting started** in the command palette reopen your saved chapters.

The chapters follow you through a practice conversation, approvals, account connections, files, skills, Ideas, and optional computer use. Practice asking a question, sending a follow-up, and checking the answer against the original notes. Exercises prepare an editable Supervised draft; you decide when to send it. The approvals chapter asks it to save a practice file so you see an approval request; approving or declining both complete it. Outlook or Gmail tasks use a connected account with email reading available; if you'd rather not connect yet, practice the same task with made-up emails. The skills chapter offers a few of your installed skills to try. Opening a draft or an unsuccessful request does not complete an exercise. **Stuck? Ask Help** in any chapter opens Help with a question about that chapter started for you.

You can explore chapters in any order, save one for later, or pause and resume. Progress is saved on this device. **Start tour** resumes your chapters; **Start again** in the guide resets progress and keeps your conversations. Computer-use guidance explains the permissions and your choice to leave it off; completing that chapter does not enable it.

Turning the experiment off hides the guide, its entry points, and its suggestions. Your progress and conversations stay saved. New installations keep the usual workspace and starter conversation until you choose to try the experiment.
